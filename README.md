# Kiri

A property management platform built for landlords who manage multiple properties and want to keep everything in one place — without relying on WhatsApp threads and spreadsheets.

## What it does

Landlords can add and manage their properties, assign tenants, track maintenance issues, handle contracts, and monitor utility payments. Tenants get their own view to report problems, submit meter readings, and stay informed about their rental.

The core idea is to replace the scattered back-and-forth of everyday property management with a single, structured workflow.

## Stack

- **Frontend** — Next.js, Tailwind CSS
- **Backend** — ASP.NET Core, REST API
- **Testing** — Jest & Playwright (frontend), xUnit (backend)

## Status

Active development. Core property and tenant management is implemented; maintenance tracking, contracts, and utilities are in progress.
